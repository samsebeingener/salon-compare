# salon-compare

Сравнение трёх маникюрных точек Москвы для инвестора: открытые данные, оценка привлекательности и честная достоверность.

Тестовое задание. После трёх разных зацепок показывается таблица полей: ссылка источника или «не найдено». Индекс привлекательности 40/25/20/15 частичный: нет данных ≠ ноль. Это ориентир, не совет покупать.

## Клонирование и запуск

```text
git clone https://github.com/samsebeingener/salon-compare.git
cd salon-compare
cp .env.example .env
```

Локально:

```text
uv sync --group dev
uv run python scripts/run_quality.py
uv run streamlit run src/salon_compare/app.py
```

Локальный Streamlit читает ключи из `.env` в корне проекта. Уже заданные переменные окружения не перезаписывает. В git файл `.env` не попадает.

Сдача заказчику (клон + `.env` по образцу + одна команда):

```text
docker compose up --build
```

Приложение: http://127.0.0.1:8501 — ключ модели для разбора зацепок не нужен. Ключи 2ГИС/Яндекс тоже не обязательны, чтобы увидеть таблицу: без них демо-тройка (сайт, «Вишня Таганская», ОГРН `1147746349552`) всё равно доходит до сбора. Поля карт будут «не найдено»; юрблок по ОГРН карты не ждёт. Если поиск карт вернул несколько салонов — нужно подтвердить, первую не берём. После сбора разбор пишется в SQLite (`data/salon-compare.sqlite`): его можно открыть снова без нового поиска и без ключа модели. После таблицы — три карточки и короткий вывод модели по уже посчитанным цифрам. Подпись: «текст модели, не инвестиционный совет». Без ключа LLM вывод пустой, приложение не падает. Поле можно поправить руками (полка «слабо», источник «правка человека»); точку можно пометить недостоверной — она остаётся в таблице, индекс этой точки не считается.

## Как уложен код

Один процесс. Слои лежат плоско в `src/salon_compare/`, без микросервисов.

| Модуль | Зачем |
|---|---|
| `app.py` | Streamlit: три зацепки, подтверждение, таблица, карточки, правки, вывод модели, список сохранённых разборов |
| `hooks.py`, `intake.py`, `resolver.py` | Тип зацепки и поиск точек на картах, без выбора «первой» |
| `maps_http.py`, `maps_parse.py`, `html_fetch.py` | JSON API 2ГИС/Яндекс и один GET открытой HTML-страницы |
| `collect.py`, `legal.py` | Поля точки и юрблок (ЕГРЮЛ, Федресурс, КАД, запасной rusprofile) |
| `score.py` | Индекс 40/25/20/15, пустой блок не ноль |
| `report.py`, `llm.py` | Карточки, правки, разбор JSON модели |
| `store.py` | SQLite разборы |
| `load_env.py`, `proxy.py` | `.env` и `trust_env` для прокси |

Тесты в `tests/`, в интернет не ходят. Качество: `uv run python scripts/run_quality.py`.

## Что хранит SQLite

Один файл `data/salon-compare.sqlite` (в git не попадает). Одна таблица `runs`:

- `id` — номер разбора;
- `created_at` — время записи;
- `payload` — JSON трёх точек (поля, полки, ссылки, флаг недостоверности).

Ключи API и модели в `payload` не пишутся. Старый разбор открывается без нового поиска и без `LLM_API_KEY`.

## Как собираются поля

На экране три поля. Тип зацепки определяется без модели. Поиск карт показывает все найденные карточки со ссылками: если их несколько — нужно подтвердить выбор, первую попавшуюся не берём. Только после трёх разных точек собираются поля: сначала API выбранной карточки, если поля нет — один GET открытой страницы, иначе «не найдено». Юрлицо: ОГРН/ИНН из зацепки или с карт, затем один GET в ЕГРЮЛ, Федресурс и КАД. Если ЕГРЮЛ не отдал карточку — HTML-поиск DuckDuckGo **POST** без ключа (`ОГРН site:rusprofile.ru/id`), затем карточка rusprofile, только если ОГРН есть в HTML; JSON `has_captcha` у платного виджета не считаем закрытой страницей. В таблице полка **слабо**, пауза 3 с между этими запросами. Федресурс и КАД с rusprofile не берём. Несколько организаций — снова список со ссылками, не «не найдено» и не первая запись. Нет ОГРН — юрполя пустые, не «долгов нет». Капчу не обходим. Ключи 2ГИС/Яндекс из `.env` прокидываются и в Docker Compose.

Прогон 2 сентября 2026 (без ключей карт): `https://pinklemon-nails.ru/baumanskaya` отдаёт **404**, живая страница студии — `baumanskaya.html`. ЕГРЮЛ и КАД отдают оболочку с капчей **без ОГРН в HTML** — в таблице это «не найдено», не «есть дела». Федресурс search открывается, но без карточки компании в теле. JSON API карт в этом прогоне не проверялся: в проекте нет `.env` с ключами. Дальше юрполя ЕГРЮЛ ищем через DuckDuckGo → rusprofile, без платного ключа.

## Прокси для LLM из РФ

Если модель с вашего компьютера в России не открывается, в `.env` задайте прокси (скопируйте из `.env.example`):

```text
HTTP_PROXY=http://USER:PASSWORD@HOST:PORT
HTTPS_PROXY=http://USER:PASSWORD@HOST:PORT
```

Это **ваш** HTTP-прокси (корпоративный или купленный), в формате `http://логин:пароль@хост:порт`. Публичные «бесплатные» списки не подходят и в репозиторий не пишем. Пустые значения — без прокси. Клиент LLM берёт `HTTP_PROXY` / `HTTPS_PROXY` из окружения. Docker Compose прокидывает их в контейнер; healthcheck на localhost через прокси не идёт.

Вывод модели в отчёте появляется только если заполнены `LLM_*`; иначе строка «вывод модели не найден (нет ключа)».

## Что за рамками

Сознательно не делаем: Instagram и прочие соцсети, Google Карты, фото интерьера, ФССП по людям, платформы с логином, микросервисы, обход капчи, совет купить конкретную точку.

Число мастеров и полный прайс для блока «масштаб» по-прежнему не парсим. Часы, дата последнего отзыва, отзывы за 90 дней и плюс/минус снимаем с открытого HTML. Расход токенов — из ответа модели; стоимость только если в `.env` заданы `LLM_USD_PER_1M_PROMPT` и `LLM_USD_PER_1M_COMPLETION`.
