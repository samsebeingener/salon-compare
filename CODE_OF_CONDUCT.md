# Нормы общения

Этот проект — публичный OSS **Никиты Куликова** ([samsebeingener](https://github.com/samsebeingener)). Сайт: [samsebeingener.ru](https://samsebeingener.ru).

## Ожидания

- Уважайте людей в issues, PR и обсуждениях.
- Критикуйте код и идеи, не личность.
- Запрещены оскорбления, травля, домогательства, дискриминация и угрозы.
- Не публикуйте чужие персональные данные без согласия.

Нарушения можно кратко описать в issue или написать на mashajetruj@gmail.com. Владелец репозитория может закрыть обсуждение, отклонить PR или ограничить участие.

Это короткий внутренний кодекс, не текст Contributor Covenant.
