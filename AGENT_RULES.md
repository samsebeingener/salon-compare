# Правила агента

Проект: сравнение трех маникюрных салонов Москвы для инвестора.

## Обязательные ограничения
- Язык: Python 3.12+.
- Веб-интерфейс: Streamlit.
- База: SQLite, один файл рядом с проектом.
- Никаких микросервисов, очередей, авторизации, личных кабинетов.
- Один процесс, один файл базы.
- Ответы модели обязательно валидируются через Pydantic.
- Тесты не ходят в интернет.
- Все внешние ответы модели и источников в тестах заменяются фикстурами.
- Ключи только через переменные окружения.
- .env не коммитится.
- Каждое значение в отчете должно иметь источник или пометку «не найдено» / «не подтверждено».
- Если данных нет, нельзя маскировать это нулем или средним.
- Сначала сценарий OpenSpec, затем падающий тест, затем реализация.
- Не добавлять новые зависимости без моего разрешения.
- Не усложнять архитектуру без моего разрешения.

## Стиль работы
- Одна задача — одна ветка — один pull request.
- Коммиты мелкие и понятные.
- Сначала тест, потом реализация.
- После каждой задачи запускаются линтер, типы и тесты.
