## MODIFIED Requirements

### Requirement: Интерфейс трёх зацепок без совета покупать
Интерфейс SHALL принимать три зацепки и MAY показать таблицу, индекс, карточки, вывод модели и список сохранённых разборов. README сдачи SHALL содержать укладку кода, сущности SQLite, границы и абзац про агента. Система MUST NOT писать «покупай».

#### Scenario: Экран сдачи
- GIVEN клон репозитория и `docker compose up`
- WHEN открывают приложение
- THEN есть три поля зацепок
- THEN после разбора есть отчёт
- THEN сохранённый разбор можно открыть без нового поиска
