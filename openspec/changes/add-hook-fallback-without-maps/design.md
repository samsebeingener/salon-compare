# Design: add-hook-fallback-without-maps

## Context

`MapsSearchResolver` уже делает fallback для сайта и ссылки записи. ОГРН, ИНН, название и свободный текст при пустом каталоге возвращают `[]` → `NEED_DISAMBIGUATION`. Живой прогон без `.env` ломается на демо-тройке, хотя `collect_place` по зацепке ОГРН юрполя собрать может.

## Goals / Non-Goals

**Goals:** три разные зацепки без ключей карт дают `READY` и таблицу; поля карт «не найдено»; ОГРН открывает юрблок.

**Non-Goals:** угадывать салон по названию в rusprofile; выбирать первую карточку карт; формула; обход капчи.

## Decisions

- Сначала поиск 2ГИС + Яндекс. Непустое — без fallback.
- Пусто: `website:` / `booking:` / `ogrn:` / `inn:` / `name:` / `text:` + нормализованная зацепка. Title — исходная строка.
- ОГРН/ИНН: `source_url` = страница ЕГРЮЛ с query. Название/текст: пустой URL, не фейковая ссылка карт.
- `MAPS_LINK` без разобранного id — пустой список, уточнение.
- Тесты: пустые каталоги + демо-тройка → `READY`; две карточки по названию → по-прежнему уточнение.

## Risks / Trade-offs

- Название без карт — точка-ярлык, не карточка организации. Рейтинг будет пустым, это честно.
- Два одинаковых названия без карт — дубль по одному `name:` id, как и задумано.
