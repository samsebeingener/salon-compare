## MODIFIED Requirements

### Requirement: README сдачи без секретов
README SHALL описывать клон, `uv`, `docker compose up`, переменные `.env` без значений ключей и что без ключей 2ГИС/Яндекс демо-тройка из подготовки всё равно доходит до таблицы: поля карт «не найдено», юрблок по ОГРН не блокируется пустым поиском карт.

#### Scenario: Демо без ключей карт в README
- GIVEN README репозитория
- WHEN читают запуск
- THEN сказано, что ключи карт не обязательны, чтобы увидеть таблицу по трём зацепкам
- THEN нет подставленных значений ключей
