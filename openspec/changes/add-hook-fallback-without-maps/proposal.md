# Proposal: add-hook-fallback-without-maps

## Why

Без ключей 2ГИС/Яндекс поиск карт пустой. Сайт ещё становится точкой с URL. Название и ОГРН дают ноль карточек → «уточните», таблица не строится. Юрблок по ОГРН при этом уже умеет работать без карт. Демо-тройка из подготовки в живом Streamlit не доходит до сбора.

## What Changes

- Если API карт вернул карточки — как сейчас: одна → берём, несколько → подтверждение, первую не выбираем.
- Если карточек ноль: сайт, запись, ОГРН, ИНН, название и свободный текст становятся **одной** точкой с id по типу зацепки. Карты в отчёте честно «не найдено». ОГРН/ИНН идут в юрблок.
- Несколько карточек с карт по-прежнему не схлопываем в fallback.
- Ссылка на карты резолвится из URL, как сейчас.
- Формулы 40/25/20/15 нет.
