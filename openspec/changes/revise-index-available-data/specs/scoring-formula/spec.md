## MODIFIED Requirements

### Requirement: Индекс 50/25/25 по доступным полям
Система SHALL считать привлекательность тремя блоками: репутация 50%, устойчивость 25%, локация 25%. Блок без данных MUST NOT давать 0 баллов и MUST NOT писать «долгов нет». Итог MUST быть частичным. Репутация MUST считаться по рейтингу и числу отзывов 2ГИС. +3 за репутацию SHALL ставиться при рейтинге выше 4.5 и ≥10 отзывов, без требования даты последнего отзыва. Устойчивость MUST считаться по дате регистрации ЕГРЮЛ/ЕГРИП и статусу, MUST NOT требовать Федресурс или КАД. Локация MUST считаться по метро и сравнению с соседями, если хотя бы одно из этих полей найдено. Масштаб MUST NOT входить в индекс. Интерфейс MUST NOT советовать «покупай».

#### Scenario: Высокий рейтинг и много отзывов без даты
- GIVEN 2ГИС 4.9 и 80 отзывов, даты последнего отзыва нет
- WHEN считают индекс
- THEN репутация +3
- THEN вклад 50% от максимума блока попадает в итог

#### Scenario: Рейтинг 4.0–4.5
- GIVEN 2ГИС 4.2 и 20 отзывов
- WHEN считают индекс
- THEN репутация +2

#### Scenario: Мало отзывов при высоком рейтинге
- GIVEN 2ГИС 4.9 и 5 отзывов
- WHEN считают индекс
- THEN репутация +2, не +3

#### Scenario: ЕГРЮЛ есть, реестры судов нет
- GIVEN дата регистрации 01.04.2014, Федресурс и КАД пустые
- WHEN считают индекс
- THEN устойчивость +3 (возраст >5 лет)
- THEN нет текста «долгов нет»

#### Scenario: Ликвидация
- GIVEN дата регистрации 2014 и статус «не действует»
- WHEN считают индекс
- THEN устойчивость 0

#### Scenario: Метро рядом
- GIVEN метро «Новослободская, 200 м»
- WHEN считают индекс
- THEN локация не пустая

#### Scenario: Нет ни одного блока
- GIVEN все сравниваемые поля пустые
- WHEN считают индекс
- THEN итог не число 0
- THEN пометка что индекс не найден
