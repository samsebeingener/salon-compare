## MODIFIED Requirements

### Requirement: Файл SQLite не коммитится
Система SHALL хранить разборы в одном файле SQLite в `data/` рядом с проектом. Git MUST игнорировать `*.db`, `*.sqlite`, `*.sqlite3` и содержимое `data/` кроме служебных заглушек.

#### Scenario: Файл базы вне git
- GIVEN рядом с проектом появился файл `*.sqlite` или `*.db`
- WHEN проверяют git status и `.gitignore`
- THEN файл базы не попадает в коммит

### Requirement: Каркас — hello, без сбора салонов
Интерфейс SHALL принимать три зацепки и MAY показать таблицу собранных полей со ссылкой или «не найдено». Система MAY открыть сохранённый разбор без нового поиска и без ключа модели. Система MUST NOT строить индекс привлекательности и MUST NOT выдавать вывод модели как инвестиционный совет.

#### Scenario: Нет сбора салонов
- GIVEN запущенное приложение
- WHEN пользователь открывает интерфейс и успешно разбирает три разные зацепки
- THEN видны поля для трёх зацепок
- THEN видна таблица полей или пометки «не найдено»
- THEN нет индекса привлекательности и нет совета «покупай»

#### Scenario: Открыть сохранённый разбор
- GIVEN в SQLite есть запись
- WHEN пользователь выбирает её и открывает
- THEN видна таблица
- THEN в интерфейсе сказано, что нового поиска нет
- THEN ключ LLM не требуется
