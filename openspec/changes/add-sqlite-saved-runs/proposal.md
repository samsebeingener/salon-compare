# Proposal: add-sqlite-saved-runs

## Why

Задание: старый отчёт открывается без ключа нейросети и без нового поиска. Сейчас таблица живёт только в сессии Streamlit: каждый rerun снова бьёт ЕГРЮЛ/DuckDuckGo/rusprofile с паузой 3 с. Есть что сохранять (поля карт и юрблок), базы ещё нет.

## What Changes

- После успешного сбора трёх точек записать строки в один SQLite-файл в `data/` рядом с проектом.
- Список сохранённых разборов в интерфейсе. Открытие показывает ту же таблицу, без HTML/API и без ключа LLM.
- Повторный rerun с теми же точками и тем же выбором юрлица не запускает сбор заново (кэш сессии).
- Ключи и `.env` в базу не пишем. Индекса привлекательности по-прежнему нет.

## Capabilities

### New Capabilities

- `saved-runs`: запись и чтение разбора из SQLite.

### Modified Capabilities

- `project-bootstrap`: интерфейс открывает сохранённый разбор; файл `data/*.sqlite` уже в gitignore.
- `open-data-collect`: сбор не повторяется на rerun с тем же ключом точек.

## Impact

- Код: `store.py`, Streamlit, фикстуры tmp_path. Стандартный `sqlite3`, без новых зависимостей.
- Не входит: формула 40/25/20/15, вывод модели, правка недостоверности.
