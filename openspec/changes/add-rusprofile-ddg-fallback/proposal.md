# Proposal: add-rusprofile-ddg-fallback

## Why

Живой GET ЕГРЮЛ/КАД/Федресурса отдаёт оболочку без карточки. Надеяться, что капча ФНС «прокатит», нельзя: юрполя всегда пустые. Поиск на rusprofile.ru закрыт (404, robots). Карточка `/id/…` открывается без капчи, а ссылку на неё находит HTML-поиск DuckDuckGo по ОГРН без API-ключа.

## What Changes

- Если официальный ЕГРЮЛ не дал дату/статус/ОКВЭД, искать `ОГРН site:rusprofile.ru/id` через `html.duckduckgo.com`, без ключа.
- Карточки `/id/…` перебирать по очереди. Значение брать только если ОГРН есть в теле HTML. Первую ссылку без сверки не брать.
- Полка **слабо**, источник — URL rusprofile. Не первоисточник ФНС.
- Учредителей и ФИО не снимать. Федресурс и КАД из rusprofile не заполнять.
- Между запросами DuckDuckGo и rusprofile — пауза (секунды), капчу не решать. Капча/403 — «не найдено», без повторов.
- Один прогон — три точки, тот же pacer на все салоны.
- Новых зависимостей и платных ключей нет. Тесты без сети.
