# Proposal: add-disambiguation-floor-mall

## Why

У сети один адрес улицы ещё не отличает филиалы в одном доме или ТЦ. В JSON 2ГИС уже есть этаж и комментарий (`address_comment`) и имя здания (`building_name`). Сейчас в подписи только улица.

## What Changes

- В адрес кандидата дописываем этаж/комментарий и название здания (ТЦ), если они есть в ответе поиска.
- Не дублируем текст, который уже есть в улице. Пустые поля не выдумываем.
- В запрос 2ГИС добавляем `items.address`, чтобы пришло имя здания. `address_comment` в базовом JSON.

## Capabilities

### New Capabilities

- (нет)

### Modified Capabilities

- `hook-intake`: подпись уточнения включает этаж и ТЦ, не только улицу.

## Impact

- Код: разбор хита 2ГИС, `TWOGIS_FIELDS`. Streamlit без новой вёрстки — та же `candidate_label`.
- Не входит: Яндекс (у него нет этого поля), смена формулы локации, новые пакеты.
