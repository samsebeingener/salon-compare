# Change: Индекс по доступным данным, без Федресурса и КАД

## Why
Федресурс и kad.arbitr.ru боту закрыты (капча/JS). HTML 2ГИС уходит в `/museum`, даты отзывов нет. Старая формула 40/25/20/15 почти всегда давала только репутацию +2.

## What
- Индекс **50/25/25**: репутация / устойчивость / локация. Масштаб не считаем (мастеров и прайса нет).
- Репутация: рейтинг 2ГИС + число отзывов. +3 без даты свежести, если отзывов ≥ 10.
- Устойчивость: дата и статус ЕГРЮЛ/ЕГРИП. Суды не запрашиваем.
- Локация: метро (метры из 2ГИС) + «соседи выше/ниже».
- Сбор MUST NOT ходить на fedresurs.ru и kad.arbitr.ru. Колонки в таблице убрать.

## Impact
`score.py`, `collect.py`, UI, тесты, ПОДГОТОВКА/README. Поля `fedresurs`/`kad` в SQLite остаются пустыми для старых прогонов.
