# Proposal: add-site-legal-enrichment-cascade

## Why

Когда 2ГИС API не отдаёт `contact_groups` и HTML карточки закрыт (`blocked`/`museum`), цепочка «о нас» обрывается — хотя сайт есть (DDG, РБК по ОГРН). ОГРН/ИНН на главной нет — нужен обход контактов и политики конфиденциальности.

## What Changes

- DDG HTML-поиск сайта по названию + адресу, если URL сайта ещё не известен.
- ОГРН → карточка РБК → URL «Сайт» → «о нас».
- Обход внутренних ссылок (контакты, политика, реквизиты) для labeled ОГРН/ИНН.
- Не угадывать домен без источника; не брать первую карточку РБК по общему названию.

## Capabilities

### Modified Capabilities

- `open-data-collect`: двусторонний каскад сайт↔юрлицо.
