# Proposal: add-twogis-moscow-region

## Why

Живой ключ 2ГИС рабочий, но поиск `Вишня Таганская` без региона даёт `itemNotFound` и 0 карточек. Документация Catalog API: текстовый `/3.0/items` нужно ограничивать `region_id`. Москва в Regions API — `32`. Задание — только Москва.

## What Changes

- Поиск филиалов 2ГИС (зацепка и запасной поиск по названию карточки) передаёт `region_id=32`.
- Соседи по точке+радиусу не трогаем: там уже есть координаты.
- Яндекс и формулу не меняем. Тесты без сети: проверяем параметры запроса, не живой ключ.

## Capabilities

### New Capabilities

- (нет)

### Modified Capabilities

- `open-data-collect`: поиск 2ГИС ограничен регионом Москва.

## Impact

- Код: `maps_http.py`, фикстуры httpx. Новых зависимостей нет.
- Не входит: ключ Яндекса, `.env` в Streamlit, формула.
