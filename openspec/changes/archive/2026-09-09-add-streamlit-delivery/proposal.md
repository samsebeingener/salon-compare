# Proposal: add-streamlit-delivery

## Why

Экран уже принимает три зацепки, показывает отчёт и сохранённые разборы. В README нет укладки кода, сущностей SQLite, границ сдачи и абзаца про агента/модели — это требование подготовки и шаг H плана.

## What Changes

- README явно описывает: что делает, как `docker compose up`, как уложены модули, таблица `runs` в SQLite, что за рамками.
- Отдельный абзац: какой агент и какие модели, что агент сделал сам, что оставил человек и почему так сдали.
- Интерфейс уже есть; этот шаг не добавляет новых экранов и зависимостей.

## Capabilities

### New Capabilities

- `delivery-readme`: состав README сдачи.

### Modified Capabilities

- `project-bootstrap`: README сдачи полный, не только hello и прокси.

## Impact

- Код: в основном `README.md` и тесты на его состав. Streamlit не переписываем.
- Не входит: HTML-парсер отзывов за 90 дней, токены/стоимость запуска, archive старых OpenSpec changes.
