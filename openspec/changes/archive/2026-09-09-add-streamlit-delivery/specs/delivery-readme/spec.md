## ADDED Requirements

### Requirement: README сдачи полный
README SHALL описать, что делает приложение, как клонировать и поднять через `docker compose up`, как уложен код в `src/salon_compare/`, какие сущности хранит SQLite, что сознательно за рамками, и отдельным абзацем — какой агент и какие модели участвовали, что агент сделал сам и почему результат оставили.

#### Scenario: Укладка кода
- GIVEN открыт README
- WHEN ищут, как устроены куски
- THEN названы модули экрана, сбора, формулы, модели и сохранения

#### Scenario: Сущности БД
- GIVEN открыт README
- WHEN ищут, что храним
- THEN указаны таблица `runs` и поле `payload`
- THEN сказано, что ключи API в базу не пишутся

#### Scenario: За рамками
- GIVEN открыт README
- WHEN ищут границы сдачи
- THEN перечислены вещи вне задачи: соцсети вроде Instagram, советы «покупай», обход капчи

#### Scenario: Агент и модели
- GIVEN открыт README
- WHEN читают абзац про агента
- THEN названы Cursor и модель Grok
- THEN видно, что агент писал OpenSpec, тесты и код, а человек мержил и держал ключи
