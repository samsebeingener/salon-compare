## ADDED Requirements

### Requirement: Streamlit читает .env без стороннего пакета
При старте Streamlit-приложения система SHALL загрузить файл `.env` из корня проекта, если он есть. Загрузка MUST использовать стандартную библиотеку, без новой зависимости. Переменная, уже заданная в окружении непустым значением, MUST NOT перезаписываться из файла. Отсутствующий файл MUST не мешать старту. Значения ключей MUST NOT попадать в git.

#### Scenario: Файл задаёт ключ карт
- GIVEN временный `.env` с `TWOGIS_API_KEY` и пустой словарь окружения
- WHEN загружают файл
- THEN в окружении этот ключ заполнен
- THEN живой `.env` репозитория в тесте не читается

#### Scenario: Окружение уже задано
- GIVEN в окружении ключ уже непустой и в файле другое значение
- WHEN загружают файл
- THEN остаётся значение из окружения

#### Scenario: Приложение вызывает загрузку
- GIVEN исходник Streamlit
- WHEN проверяют старт
- THEN есть вызов загрузки `.env` из корня проекта
