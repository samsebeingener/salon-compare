## Purpose

Сбор открытых полей трёх точек.

## MODIFIED Requirements

### Requirement: Каскад поля API затем HTML затем не найдено
Для каждого сравниваемого поля система SHALL сначала взять значение из JSON API 2ГИС и/или Яндекс. Если поля нет в ответе (пусто, нет ключа, нет ключа API, ошибка запроса), система SHALL сделать не больше одного GET открытой HTML-страницы той же карточки. Если HTML не дал поле — значение MUST быть «не найдено», без нуля и без среднего. Сбор SHALL загружать карточку по идентификатору уже выбранной точки. Несколько результатов поиска на шаге зацепок MUST NOT превращаться в «не найдено» на шаге полей.

#### Scenario: Полный ответ API
- GIVEN фикстура API 2ГИС и Яндекс с рейтингом и числом отзывов
- WHEN собирают поля точки
- THEN оба рейтинга заполнены из API со ссылкой источника
- THEN HTML для этих полей не вызывается

#### Scenario: В API нет рейтинга, HTML отдал
- GIVEN API Яндекса без рейтинга и HTML карточки с рейтингом
- WHEN собирают поля точки
- THEN рейтинг Яндекса берётся из HTML со ссылкой страницы
- THEN поле не заполняется нулём

#### Scenario: API пусто и HTML закрыт
- GIVEN пустой API и HTML с капчей, логином или 403
- WHEN собирают поля точки
- THEN рейтинг и отзывы этой карты имеют пометку «не найдено»
- THEN значение не подменяется нулём или средним
- THEN защиту (капча/логин) не обходят повторными запросами

#### Scenario: Поиск нашёл несколько карточек
- GIVEN поиск по зацепке вернул больше одной карточки
- WHEN ещё нет подтверждения пользователя
- THEN поля не заполняются как «не найдено» из‑за числа хитов
- THEN сначала запрашивается подтверждение со ссылками
