# Design: fix-table-stripe-contrast

## Context

`.sc-row-even { background: #f6f7f9 }` ломает тёмную тему: markdown оставляет светлый `color`, фон почти белый.

## Decisions

- Фон: `rgba(128, 128, 128, 0.18)` — чуть темнее на светлом, чуть светлее на тёмном.
- `.sc-cell { color: inherit }` — не задавать свой цвет текста.
- Не прятать строки «не найдено»: данные честные, чинится только видимость.

## Risks / Trade-offs

- [Zebra почти незаметна] → 0.18 достаточно для чередования без засветки.
