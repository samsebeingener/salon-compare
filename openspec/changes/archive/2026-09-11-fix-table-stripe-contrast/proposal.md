# Proposal: fix-table-stripe-contrast

## Why

Zebra таблицы сравнения заливала чётные строки жёстким `#f6f7f9`. В тёмной теме Streamlit текст светлый — строка выглядит пустой белой полосой, подписи и «не найдено» не читаются.

## What Changes

- Фон зебры — полупрозрачный серый (`rgba`), без светлой заливки.
- Текст ячейки наследует цвет темы.
- Спека: zebra MUST сохранять контраст в светлой и тёмной теме.

## Capabilities

### Modified Capabilities

- `streamlit-ui`: контраст чередования строк таблицы.

## Impact

- `app.py` CSS `.sc-row-even`.
- Тест: в `app.py` нет `#f6f7f9`.
