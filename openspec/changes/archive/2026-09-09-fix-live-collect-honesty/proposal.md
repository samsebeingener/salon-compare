# Proposal: fix-live-collect-honesty

## Why

Живой прогон 2 сентября 2026: `https://pinklemon-nails.ru/baumanskaya` отдаёт 404 (живая страница `baumanskaya.html`). ЕГРЮЛ и КАД — HTML-оболочка с капчей без ОГРН в теле. Федресурс search 200 без ОГРН в HTML. Маркер «войти» на КАД помечает страницу закрытой; оболочка КАД при этом содержит «арбитраж» и могла бы дать ложное «есть дела». Radio подставляет первую карточку, если выбор пуст. ИНН с карт уходит в URL Федресурса/КАД как ОГРН. Соседи 500 м в API не запрашиваются: нет координат.

## What Changes

- Не подставлять первую карточку в radio.
- «Войти» в меню не равно капче. 401/403/429 и настоящая капча — закрыто.
- Реестр без ОГРН/ИНН в теле HTML — «не найдено», не «есть дела» и не «не обнаружено».
- ИНН не подставлять в Федресурс и КАД. Только ОГРН 13/15 цифр.
- 2ГИС: запросить точку; соседи — radius 500 м по координатам, без себя.
- User-Agent на HTML GET. 404 сайта — «не найдено».
- README: факт прогона (404 путь, реестры-оболочки, ключи карт).
- Не обходим капчу. Не меняем зацепку в ПОДГОТОВКА молча. Формулы нет.

- `hook-intake`: подтверждение без первой карточки по умолчанию.
- `project-bootstrap`: README фиксирует живой прогон.

- Новых зависимостей нет. Тесты без сети.
- Ключей карт в этой среде не было — JSON API карт в прогоне не проверялся.
