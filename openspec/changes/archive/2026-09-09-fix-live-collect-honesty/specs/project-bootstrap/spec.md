## MODIFIED Requirements

### Requirement: Каркас — hello, без сбора салонов
Интерфейс SHALL принимать три зацепки и MAY показать таблицу собранных полей со ссылкой или «не найдено», включая юрполя. Система MUST NOT строить индекс привлекательности и MUST NOT выдавать вывод модели как инвестиционный совет. README SHALL кратко фиксировать живой прогон: 404 демо-пути сайта, реестры-оболочки без обхода капчи, ключи карт для JSON API.

#### Scenario: Нет сбора салонов
- GIVEN запущенное приложение
- WHEN пользователь открывает интерфейс и успешно разбирает три разные зацепки
- THEN видны поля для трёх зацепок
- THEN видна таблица полей или пометки «не найдено»
- THEN нет индекса привлекательности и нет совета «покупай»

#### Scenario: README описывает прогон
- GIVEN клонированный репозиторий
- WHEN открывают README
- THEN есть пометка про 404 пути Pinklemon и про оболочки реестров
