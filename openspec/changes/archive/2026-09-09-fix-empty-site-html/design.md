# Design: fix-empty-site-html

## Context

`_site_urls` кладёт зацепку как есть. 404 → `classify_fetch` → `empty` → «о нас» missing, хотя `{path}.html` открывается. `resolve_legal_orgs` берёт ОГРН только из зацепки или `MapCard.ogrn`. 2ГИС Places на Pink Lemon / Вишня `ogrn` не возвращает.

## Goals / Non-Goals

**Goals:** открыть живой `.html` после 404 без расширения; не терять ОГРН, если сайт сам его подписал.

**Non-Goals:** поиск РБК/ЕГРЮЛ по вывеске; `items.itin` без разрешения ключа; менять `search_query` (суффикс `baumanskaya` в 2ГИС не даёт карточку на Ладожской); обход капчи nalog.ru.

## Decisions

- Суффикс только если статус первого GET — `empty`, путь без `.` в последнем сегменте. `blocked` не дополняем.
- ОГРН с сайта: regex `огрн` + опционально `/огрнип` + 13 или 15 цифр. Не `_OGRN.findall` по всей странице.
- Карта важнее сайта: если `twogis.ogrn` валиден, сайтный ОГРН не подменяет.
- Несколько ОГРН на странице — берём первое совпадение маркера (как один org). Два разных маркера без уточнения не плодим в этом change.

## Risks

- [Чужой `.html` на том же пути] → полка found со ссылкой на фактический URL.
- [В подвале чужой ОГРН агрегатора] → weakly дальше по каскаду реестров, источник — страница сайта.
