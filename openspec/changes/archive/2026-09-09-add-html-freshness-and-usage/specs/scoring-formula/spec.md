## MODIFIED Requirements

### Requirement: Индекс 40/25/20/15 без подстановки нуля
Система SHALL считать привлекательность четырьмя блоками: репутация 40%, устойчивость 25%, локация 20%, масштаб 15%. Блок без данных MUST NOT давать 0 баллов и MUST NOT писать «долгов нет». Итог MUST быть частичным: сумма вкладов посчитанных блоков, либо пометка «не найдено», если ни один блок не посчитан. Две карты MUST NOT усредняться. Если у двух карт есть рейтинг и известны даты последних отзывов, в баллы MUST идти более свежий источник, без среднего. Если дат нет у обеих — «не ясно какой свежее». +3 MUST ставиться только при рейтинге выше 4.5 и отзывах за 90 дней у выбранного источника. Много минусов при явной разбивке MUST давать 0. Нет разбивки — негатив 0 MUST NOT ставиться. Устойчивость MUST считаться только если Федресурс и КАД имеют полку found. Соседи MUST NOT быть пятым весом. Локация и масштаб без типа точки и числа мастеров MUST остаться несчитанными. Интерфейс MUST NOT советовать «покупай». Точка, помеченная недостоверной, MUST сохранить поля в отчёте и MUST NOT получить числовой индекс.

#### Scenario: Две карты, неизвестна свежесть
- GIVEN рейтинг Яндекса 4.9 и рейтинг 2ГИС 4.1, дат отзывов нет
- WHEN считают индекс
- THEN блок репутации без баллов
- THEN причина «не ясно какой свежее»
- THEN среднее 4.5 не используется

#### Scenario: Одна карта с высоким рейтингом
- GIVEN только 2ГИС 4.6 и отзывы, Яндекс пуст, дат свежести нет
- WHEN считают индекс
- THEN репутация +2, не +3
- THEN вклад 40% от максимума блока с этими баллами попадает в итог

#### Scenario: Свежий Яндекс против старого 2ГИС
- GIVEN Яндекс 4.9 с отзывом 20.08.2026 и 2ГИС 4.1 с отзывом 01.01.2026
- WHEN считают индекс на 02.09.2026
- THEN в репутацию идёт 4.9, не среднее

#### Scenario: Высокий рейтинг и отзывы за 90 дней
- GIVEN только 2ГИС 4.8, 80 отзывов, последний 01.08.2026, дата расчёта 02.09.2026
- WHEN считают индекс
- THEN репутация +3

#### Scenario: ЕГРЮЛ есть, реестры пустые
- GIVEN дата регистрации 2014 и Федресурс и КАД «не найдено»
- WHEN считают индекс
- THEN устойчивость не считается
- THEN нет текста «долгов нет»

#### Scenario: Реестры открылись
- GIVEN Федресурс и КАД с полкой found, оба значения «не обнаружено», дата регистрации 01.04.2014, дата расчёта 02.09.2026
- WHEN считают индекс
- THEN возраст >5 лет (+3) и бонус «нет судов» (+1)

#### Scenario: Нет ни одного блока
- GIVEN все сравниваемые поля пустые
- WHEN считают индекс
- THEN итог не число 0
- THEN пометка что индекс не найден

#### Scenario: Недостоверный объект без числа
- GIVEN точка с рейтингом, по которому индекс был бы числом
- WHEN объект помечен недостоверным
- THEN индекс не число
- THEN пояснение содержит «недостоверный»
