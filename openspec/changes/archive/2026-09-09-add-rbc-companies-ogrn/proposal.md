# Proposal: add-rbc-companies-ogrn

## Why

Живой прогон: ЕГРЮЛ и КАД — капча без карточки, DuckDuckGo→rusprofile часто пустой. Юрполя «не найдено», хотя ОГРН известен. Открытый поиск [РБК Компании](https://companies.rbc.ru/search/?query=1147746349552) по тому же ОГРН отдаёт карточку в HTML без капчи: статус, дата регистрации, категория.

## What Changes

- Если официальный ЕГРЮЛ не дал дату/статус/деятельность, один GET `https://companies.rbc.ru/search/?query={ОГРН}`.
- Значения только из блока карточки, где тот же ОГРН. Заголовок «результаты по запросу» сам по себе не считается находкой.
- Полка **слабо**, источник — URL поиска. Федресурс и КАД с РБК не берём. Учредителей и ФИО не снимаем.
- Если карточки нет или страница закрыта — как сейчас, DuckDuckGo→rusprofile. Капчу не решаем.
- Новых зависимостей нет. Тесты без сети.
