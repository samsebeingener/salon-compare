# Design: add-rbc-companies-ogrn

## Context

GET `egrul.nalog.ru` в живом прогоне без ОГРН в теле. Поиск РБК `https://companies.rbc.ru/search/?query=1147746349552` — HTTP 200, в HTML блок `company-card info-card` со статусом «Действует», датой `01.04.2014`, ОГРН в `<em>`, ссылкой `/id/1147746349552-…`. Цифры ОГРН ещё раз в заголовке выдачи — этого мало.

## Goals / Non-Goals

**Goals:** заполнить дату, статус, вид деятельности по ОГРН, когда ФНС молчит; один GET; полка слабо.

**Non-Goals:** Playwright/JS, новые поля (выручка, директор), Федресурс/КАД из РБК, обход капчи.

## Decisions

- Каскад: официальный ЕГРЮЛ → если все три поля пустые → GET РБК поиска → если снова пусто → DuckDuckGo→rusprofile.
- URL: `https://companies.rbc.ru/search/?query={ogrn}`. Не API, не второй GET карточки `/id/…`, если поиск уже содержит карточку.
- Карточка засчитывается только если в блоке `company-card` есть этот ОГРН (`ОГРН` или `/id/{ogrn}-`).
- Разбор: статус из `company-status-badge`, дата с маркера «Дата регистрации», деятельность — последняя крошка `category-breadcrumb__item` (не «оквэд» из подвала сайта).
- `Trust.WEAK`, `source_url` = URL поиска. Тот же `LegalParser.parse_egrul` на вырезанном блоке + крошка, если деятельность пустая.
- Пауза 3 с на РБК не вешаем: один GET, как ЕГРЮЛ.
- Капча/403 РБК → этот шаг пустой, дальше rusprofile.

## Risks / Trade-offs

- Вёрстка РБК может уехать в чистый React без карточки в HTML — тогда снова «не найдено».
- Агрегатор, не ФНС: полка слабо обязательна.
