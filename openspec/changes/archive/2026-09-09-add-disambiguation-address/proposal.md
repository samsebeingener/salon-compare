# Proposal: add-disambiguation-address

## Why

Поиск по бренду сети даёт несколько карточек с одним названием. Сейчас в радиокнопке только имя и ссылка 2ГИС — филиалы не отличить без клика по каждой.

## What Changes

- В список уточнения точки попадает адрес с карты (если он есть в JSON поиска).
- Подпись: название — адрес — ссылка. Нет адреса — как сейчас, название и ссылка, без выдуманного адреса.
- Адрес берём из ответа поиска, без второго запроса карточки.

## Capabilities

### New Capabilities

- (нет)

### Modified Capabilities

- `hook-intake`: при нескольких карточках с одним названием пользователь видит адрес каждой.

## Impact

- Код: `VenueCandidate`, разбор хитов 2ГИС/Яндекс, подпись в Streamlit.
- Не входит: автовыбор филиала, смена формулы, новые пакеты.
