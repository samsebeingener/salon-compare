## ADDED Requirements

### Requirement: Подпись карточки в уточнении включает адрес
Если по зацепке несколько карточек карт, система SHALL показать для каждой не только название и ссылку, но и адрес из ответа поиска, когда он есть. Несколько филиалов с одним названием MUST различаться адресом. Если адреса в ответе нет, система MUST NOT выдумывать его и MUST оставить название со ссылкой.

#### Scenario: Сеть с одним названием и разными адресами
- GIVEN поиск вернул две карточки с названием «I like nails, студия маникюра» и адресами «Москва, Бауманская» и «Москва, Таганская»
- WHEN показывают список уточнения
- THEN в подписи первой карточки есть «Москва, Бауманская»
- THEN в подписи второй карточки есть «Москва, Таганская»
- THEN обе ссылки карт остаются в подписи

#### Scenario: Адрес в поиске пустой
- GIVEN две карточки с одним названием и без адреса в ответе поиска
- WHEN показывают список уточнения
- THEN подпись содержит название и ссылку
- THEN в подписи нет выдуманного адреса
