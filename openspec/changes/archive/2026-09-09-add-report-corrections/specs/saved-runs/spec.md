## MODIFIED Requirements

### Requirement: Открытие сохранённого разбора
Интерфейс SHALL открыть сохранённый разбор без нового поиска карт и HTML. На экране MUST быть таблица полей, карточки и индекс по сохранённым значениям. Ключ модели MUST NOT быть обязателен, чтобы увидеть таблицу и карточки. Правка поля или пометка недостоверности MAY пересчитать индекс в сессии без нового сбора.

#### Scenario: Чтение не ходит в сеть
- GIVEN запись в SQLite
- WHEN загружают разбор
- THEN возвращаются те же строки
- THEN загрузчик HTML не вызывается

#### Scenario: Открыли старый разбор
- GIVEN в SQLite есть сохранённые три точки
- WHEN открывают разбор
- THEN поля на месте без HTML-запроса
- THEN ключ LLM не требуется для таблицы и карточек
