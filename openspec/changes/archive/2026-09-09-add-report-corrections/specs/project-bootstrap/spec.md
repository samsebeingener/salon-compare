## MODIFIED Requirements

### Requirement: Интерфейс трёх зацепок без совета покупать
Интерфейс SHALL принимать три зацепки и MAY показать таблицу собранных полей, частичный индекс 40/25/20/15, три карточки салона, вывод модели и список сохранённых разборов. README сдачи SHALL содержать укладку кода, сущности SQLite, границы и абзац про агента. Вывод модели MUST быть подписан как «текст модели, не инвестиционный совет». Система MUST NOT выдавать вывод как инвестиционный совет и MUST NOT писать «покупай».

#### Scenario: Экран после сбора
- GIVEN три разные зацепки доведены до сбора
- WHEN смотрят отчёт
- THEN в таблице есть строка индекса или пометка «не найдено»
- THEN есть карточки точек
- THEN подпись вывода модели не выдаёт его за инвестиционный совет
- THEN нет совета «покупай»

#### Scenario: Экран сдачи
- GIVEN клон репозитория и `docker compose up`
- WHEN открывают приложение
- THEN есть три поля зацепок
- THEN после разбора есть отчёт
- THEN сохранённый разбор можно открыть без нового поиска
