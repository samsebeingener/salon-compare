## ADDED Requirements

### Requirement: Карточки трёх точек
После сбора полей система SHALL показать три карточки салона. Каждая карточка MUST содержать поля со ссылкой источника или «не найдено» и список полей, которых нет. Система MUST NOT подставлять ноль вместо пустого поля.

#### Scenario: Карточка после сбора
- GIVEN три точки с частью полей пустыми
- WHEN строят карточки
- THEN у каждой есть заголовок и список отсутствующих полей
- THEN найденное поле несёт значение и ссылку или пометку слабо

### Requirement: Вывод модели только по цифрам
Система SHALL вызвать модель только если заданы `LLM_API_KEY`, `LLM_BASE_URL` и `LLM_MODEL`. Промпт MUST содержать уже посчитанный индекс и значения полей, MUST NOT содержать совет «покупай». Ответ MUST разбираться Pydantic-схемой. Интерфейс MUST подписать вывод: «текст модели, не инвестиционный совет». Отсутствие ключа MUST NOT ронять приложение.

#### Scenario: Нет ключа модели
- GIVEN в окружении нет `LLM_API_KEY`
- WHEN запрашивают вывод
- THEN клиент возвращает пустую строку
- THEN разбор даёт отсутствие вывода, без исключения

#### Scenario: Пустой JSON
- GIVEN ответ модели `{}` или пустая строка
- WHEN разбирают вывод
- THEN результат отсутствует
- THEN исключения нет

#### Scenario: Лишние поля
- GIVEN JSON с обязательными строками и неизвестным полем
- WHEN разбирают вывод
- THEN обязательные поля приняты
- THEN лишнее поле отброшено

#### Scenario: Число строкой
- GIVEN `compared_index` как строка `"26.7"`
- WHEN разбирают вывод
- THEN значение 26.7 как число

### Requirement: Правка поля и недостоверный объект
Человек MAY заменить значение поля. Исправленное поле MUST иметь полку «слабо» и источник «правка человека». Человек MAY пометить всю точку недостоверной. После правки или пометки система SHALL пересчитать индекс. Недостоверная точка MUST остаться в таблице с пометкой, её индекс MUST NOT быть числом.

#### Scenario: Правка рейтинга
- GIVEN точка с рейтингом 2ГИС 4.1
- WHEN человек ставит 4.8
- THEN значение 4.8, полка слабо, источник «правка человека»
- THEN индекс считается по новому значению

#### Scenario: Недостоверный объект
- GIVEN точка, у которой индекс был числом
- WHEN её помечают недостоверной
- THEN индекс не число
- THEN в пояснении есть «недостоверный»
