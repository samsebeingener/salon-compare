## ADDED Requirements

### Requirement: Разбор сохраняется в SQLite
После сбора полей трёх точек система SHALL записать строки в один файл SQLite в каталоге `data/` рядом с проектом. В записи MUST быть дата и JSON полей. Система MUST NOT класть в базу ключи API или содержимое `.env`.

#### Scenario: Сохранить и прочитать
- GIVEN три `PlaceRecord` из фикстуры (без сети)
- WHEN сохраняют разбор и читают его по id
- THEN поля совпадают, включая полку weakly и URL источника
- THEN файл лежит в переданном пути SQLite

### Requirement: Сохранённый разбор без нового поиска
Открытие сохранённого разбора SHALL показать таблицу полей. Система MUST NOT вызывать HTML, карты и DuckDuckGo при открытии.

#### Scenario: Чтение не ходит в сеть
- GIVEN запись в SQLite
- WHEN загружают разбор
- THEN возвращаются те же строки
- THEN загрузчик HTML не вызывается
