## MODIFIED Requirements

### Requirement: Индекс 40/25/20/15 без подстановки нуля
Система SHALL считать привлекательность четырьмя блоками: репутация 40%, устойчивость 25%, локация 20%, масштаб 15%. Если у двух карт есть рейтинг и известны даты последних отзывов, в баллы MUST идти более свежий источник, без среднего. Если дат нет у обеих — «не ясно какой свежее». +3 MUST ставиться только при рейтинге выше 4.5 и отзывах за 90 дней у выбранного источника. Много минусов при явной разбивке MUST давать 0. Нет разбивки — негатив 0 MUST NOT ставиться.

#### Scenario: Свежий Яндекс против старого 2ГИС
- GIVEN Яндекс 4.9 с отзывом 20.08.2026 и 2ГИС 4.1 с отзывом 01.01.2026
- WHEN считают индекс на 02.09.2026
- THEN в репутацию идёт 4.9, не среднее

#### Scenario: Высокий рейтинг и отзывы за 90 дней
- GIVEN только 2ГИС 4.8, 80 отзывов, последний 01.08.2026, дата расчёта 02.09.2026
- WHEN считают индекс
- THEN репутация +3
