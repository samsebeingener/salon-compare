# Proposal: add-html-freshness-and-usage

## Why

В отчёте нет часов, даты последнего отзыва, признака «есть отзывы за 90 дней» и плюс/минус. HTML-парсер сейчас пустой. Расход токенов и оценка денег запуска не показываются. Это дырки подготовки (репутация/масштаб в таблице и блок «Расход»).

## What Changes

- Разбор открытого HTML без новых пакетов: часы, дата последнего отзыва, плюс/минус если площадка сама написала цифры. Нет в HTML — «не найдено», не ноль.
- По датам отзывов выбираем более свежую карту для баллов. +3 только если рейтинг >4.5 и есть отзывы за 90 дней. Много минусов без выдумки — 0. Нет дат — по-прежнему «не ясно какой свежее».
- Ответ LLM: `usage` токенов. Стоимость — только если заданы `LLM_USD_PER_1M_PROMPT` и `LLM_USD_PER_1M_COMPLETION`, иначе «не найдено».
- Старый SQLite-список строк читается. Новых зависимостей нет.

## Capabilities

### New Capabilities

- `html-freshness`: часы, свежесть отзывов, плюс/минус из HTML.
- `run-usage`: токены и опциональная стоимость запуска.

### Modified Capabilities

- `open-data-collect`: каскад заполняет новые поля.
- `scoring-formula`: свежий источник и +3 / негатив 0.
- `project-bootstrap`: строка расхода в отчёте.

## Impact

- Код: `html_parse.py`, `collect.py`, `score.py`, `llm.py`, `store.py`, Streamlit, README.
- Не входит: график отзывов по месяцам, парсер мастеров/прайса для блока масштаб, обход капчи.
