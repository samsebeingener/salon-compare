## MODIFIED Requirements

### Requirement: Индекс 40/25/20/15 без подстановки нуля
Система SHALL считать привлекательность четырьмя блоками: репутация 40%, устойчивость 25%, локация 20%, масштаб 15%. Блок без данных MUST NOT давать 0 баллов и MUST NOT писать «долгов нет». Итог MUST быть частичным: сумма вкладов посчитанных блоков, либо пометка «не найдено», если ни один блок не посчитан. Две карты MUST NOT усредняться. Если у обеих есть рейтинг и нет даты свежести ленты, репутация MUST не гадать источник: «не ясно какой свежее». +3 за репутацию MUST NOT ставиться без признака свежих отзывов. Устойчивость MUST считаться только если Федресурс и КАД имеют полку found. Соседи MUST NOT быть пятым весом. Локация и масштаб без типа точки и числа мастеров MUST остаться несчитанными. Интерфейс MUST NOT советовать «покупай». Точка, помеченная недостоверной, MUST сохранить поля в отчёте и MUST NOT получить числовой индекс.

#### Scenario: Недостоверный объект без числа
- GIVEN точка с рейтингом, по которому индекс был бы числом
- WHEN объект помечен недостоверным
- THEN индекс не число
- THEN пояснение содержит «недостоверный»
