## MODIFIED Requirements

### Requirement: Интерфейс трёх зацепок без совета покупать
Интерфейс SHALL принимать три зацепки и MAY показать таблицу собранных полей, частичный индекс 40/25/20/15, три карточки салона и вывод модели. Вывод модели MUST быть подписан как «текст модели, не инвестиционный совет». Система MUST NOT писать «покупай».

#### Scenario: Экран после сбора
- GIVEN три разные зацепки доведены до сбора
- WHEN смотрят отчёт
- THEN в таблице есть строка индекса или пометка «не найдено»
- THEN есть карточки точек
- THEN подпись вывода модели не выдаёт его за инвестиционный совет
- THEN нет совета «покупай»
