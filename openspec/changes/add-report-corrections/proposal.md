# Proposal: add-report-corrections

## Why

Таблица и индекс есть, сравнительного отчёта нет: нет карточек салона, нет вывода модели по цифрам, нет правки поля и пометки «недостоверный». Сценарии 6 и 7 из подготовки.

## What Changes

- Три карточки: все поля со ссылкой или «не найдено», список того, чего нет.
- Вывод модели только по уже посчитанным цифрам. Подпись «текст модели, не инвестиционный совет». Нет ключа — не падаем, вывод пустой.
- Ответ модели — JSON в Pydantic. Пустой JSON, лишние поля, число строкой — приложение не падает.
- Правка поля человеком: полка «слабо», источник «правка человека», индекс пересчитывается.
- Пометка объекта «недостоверный»: салон остаётся в таблице, индекс этой точки не число.
- Новых зависимостей нет. Тесты без сети, ответы модели — фикстуры.

## Capabilities

### New Capabilities

- `report-corrections`: карточки, разбор JSON модели, правки, недостоверный объект.

### Modified Capabilities

- `project-bootstrap`: отчёт после сбора — таблица, карточки, вывод модели без совета «покупай».
- `scoring-formula`: недостоверный объект не даёт числовой индекс.
- `saved-runs`: сохранённый разбор показывает карточки; правки в сессии без нового поиска.
