## ADDED Requirements

### Requirement: Ссылка Яндекс Карт ищет 2ГИС по slug
Если зацепка — URL `yandex.ru/maps` с путём `/org/{slug}/…`, где slug не из одних цифр, резолвер SHALL поискать 2ГИС по slug (подчёркивания заменить на пробелы). Несколько хитов MUST показать на подтверждение, первую MUST NOT брать. Если хитов нет или slug — только цифры, система MUST оставить кандидата `yandex:{id}` без вызова API Яндекса и MUST NOT выдумывать карточку 2ГИС.

#### Scenario: Slug даёт две карточки 2ГИС
- GIVEN ссылка `https://yandex.ru/maps/org/vishnya/123` и поиск 2ГИС по «vishnya» вернул две карточки
- WHEN резолвят зацепку
- THEN статус не «готово», пока пользователь не выберет
- THEN в списке ссылки обеих карточек 2ГИС

#### Scenario: Только числовой id
- GIVEN ссылка `https://yandex.ru/maps/org/123456`
- WHEN резолвят зацепку
- THEN поиск 2ГИС не вызывается
- THEN один кандидат с id `yandex:123456`
