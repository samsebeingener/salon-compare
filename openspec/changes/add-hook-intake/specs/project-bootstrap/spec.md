## Purpose

Каркас репозитория salon-compare: одна команда качества, Docker Compose, секреты в образце окружения. Интерфейс принимает зацепки, но не собирает салоны.

## MODIFIED Requirements

### Requirement: Каркас — hello, без сбора салонов
Интерфейс SHALL принимать три зацепки (поля ввода). Система MUST NOT собирать данные салонов с карт и MUST NOT строить сравнительный отчёт. Hello-заглушка без полей ввода больше не требуется.

#### Scenario: Нет сбора салонов
- GIVEN запущенное приложение
- WHEN пользователь открывает интерфейс
- THEN видны поля для трёх зацепок
- THEN нет сравнительного отчёта по салонам
