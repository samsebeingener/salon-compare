## ADDED Requirements

### Requirement: Расход на экране включает добор полей
После свежего сбора с ключом модели экран «Расход» SHALL отражать сумму токенов и стоимости добора MISSING-полей и последующего вердикта. Отсутствие ключа MUST по-прежнему не требовать LLM для таблицы полей. Пустой usage добора MUST NOT обнулять уже показанный расход.

#### Scenario: Добор был, вердикт тоже
- GIVEN свежий сбор вызвал добор с ненулевым usage и затем вердикт с ненулевым usage
- WHEN смотрят блок «Расход»
- THEN токены — сумма обоих шагов, не только вердикта

#### Scenario: Нет ключа — таблица без добора
- GIVEN в окружении нет ключа модели
- WHEN смотрят отчёт после сбора
- THEN таблица полей есть
- THEN добор не обязателен
- THEN расход пустой или «не найден», без падения
