## ADDED Requirements

### Requirement: ОГРН ищет карты по бренду РБК, не только по цифрам
Если поиск карт по цифрам ОГРН пуст, система SHALL взять имя бренда с карточки РБК этого ОГРН и поискать 2ГИС/Яндекс по этому имени. Несколько карточек MUST показать на подтверждение, первую MUST NOT брать. Поиск РБК по общему словосочетанию вроде «ногтевой сервис» MUST NOT подставлять юрлицо автоматически.

#### Scenario: Цифры пусты, бренд нашёл две точки 2ГИС
- GIVEN ОГРН `1147746349552`, поиск карт по цифрам пуст, бренд «I LIKE NAILS», 2ГИС вернул две фирмы
- WHEN разбирают зацепку
- THEN статус уточнения, не READY
- THEN обе ссылки 2ГИС видны

#### Scenario: Цифры пусты, бренд нашёл одну точку
- GIVEN те же цифры пусты и одна карточка 2ГИС по бренду
- WHEN разбирают зацепку
- THEN эта карточка в кандидатах слота ОГРН
