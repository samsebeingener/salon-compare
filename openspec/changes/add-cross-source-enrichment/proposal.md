# Proposal: add-cross-source-enrichment

## Why

Зацепка сейчас режет остальные источники: сайт — только HTML сайта; ОГРН — поиск карт по цифрам (0 хитов). В JSON 2ГИС есть сайт, часы, юрлицо, но поля `contact_groups` / `org` мы даже не просим. Поиск РБК по обрывку «ногтевой сервис» даёт сотни тысяч юрлиц — первую брать нельзя.

## What Changes

- Любая зацепка дальше идёт во все открытые источники, которые уже есть (карты, сайт, РБК/ЕГРЮЛ). Не «если дали сайт — карты не смотрим».
- С карточки 2ГИС/Яндекс забираем сайт (и часы, если они в JSON). Поле «о нас» грузим с этого URL, даже если зацепка была ОГРН или название.
- ОГРН: имя бренда с карточки РБК (например I LIKE NAILS) → поиск 2ГИС/Яндекс по этому имени. Несколько карточек — спросить. Первую не брать. Поиск РБК по общему «ногтевой сервис» автоматом не подставляем.
- `items.org` и `items.contact_groups` в запросе 2ГИС, чтобы не выкидывать ОГРН и сайт.
- Новых пакетов нет. Капчу не обходим. Тесты без сети.
