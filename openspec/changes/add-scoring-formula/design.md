# Design: add-scoring-formula

## Decisions

- Веса: репутация 0.40, устойчивость 0.25, локация 0.20, масштаб 0.15. Максимум сырых баллов: 3 / 4 / 3 / 3.
- Вклад блока: `100 * weight * (raw / max)`, raw может быть отрицательным (суды). Нет raw — вклада нет.
- Дата «сегодня» в проде `date.today()`, в тестах фиксируем `2026-09-02`.
- Одна карта с рейтингом: ≥4.5 или 4.0–4.5 → +2; ниже 4.0 → +1. Две карты без дат → блок пустой.
- Устойчивость: `fedresurs.trust == found` и `kad.trust == found`. Возраст: >5 лет +3; 3–5 +2; <1 +1; 1–3 года в подготовке нет — берём +2 как середину 3–5 не врём: **1–3 года +1** (ближе к «молодой», не к «>5»).
- «не обнаружено» на обоих реестрах → +1 к судам. «банкрот»/«есть дела» → −2.
- Локация и масштаб в этой версии всегда пустые (нет типа/мастеров в полях).

## Risks

- Демо без Яндекса и без Федресурс/КАД даст индекс только из одной карты 2ГИС или «не найдено».
- 1–3 года в подготовке не расписаны явно.
