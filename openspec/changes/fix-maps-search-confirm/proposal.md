# Proposal: fix-maps-search-confirm

## Why

Живое приложение не ищет карточки на картах на шаге зацепок. Несколько результатов API молча превращались в «не найдено». Это ломает согласованное правило: не угадывать, показать ссылки и спросить, какую точку разбирать. Ключи карт не попадали в Docker.

## What Changes

- Поиск 2ГИС/Яндекс на шаге резолвера, не после «готово».
- Несколько карточек → статус уточнения, список со ссылками, подтверждение выбора. Не «не найдено».
- Ноль карточек → уточнить зацепку, не таблица пустых полей как будто точка выбрана.
- Запрос поиска зависит от типа зацепки (сайт → домен, ОГРН → цифры, ссылка на карту → эта карточка).
- Сбор полей по id выбранной карточки, не «взять единственный результат поиска».
- Compose прокидывает ключи карт и LLM из `.env`.

## Capabilities

### Modified Capabilities

- `hook-intake`: живой резолвер — поиск карт; подтверждение выбора из списка ссылок.
- `open-data-collect`: несколько хитов поиска не равны отсутствию поля.
- `project-bootstrap`: переменные ключей в Compose.
