## MODIFIED Requirements

### Requirement: Индекс 40/25/20/15 без подстановки нуля
Система SHALL считать привлекательность четырьмя блоками: репутация 40%, устойчивость 25%, локация 20%, масштаб 15%. Блок без данных MUST NOT давать 0 баллов и MUST NOT писать «долгов нет». Итог MUST быть частичным: сумма вкладов посчитанных блоков, либо пометка «не найдено», если ни один блок не посчитан. Репутация MUST считаться только по 2ГИС. Система MUST NOT усреднять две карты и MUST NOT ждать Яндекс. Если рейтинга 2ГИС нет — репутация не считается. +3 за репутацию MUST NOT ставиться без признака свежих отзывов 2ГИС. Устойчивость MUST считаться только если Федресурс и КАД имеют полку found. Соседи MUST NOT быть пятым весом. Локация и масштаб без типа точки и числа мастеров MUST остаться несчитанными. Интерфейс MUST NOT советовать «покупай».

#### Scenario: Рейтинг 2ГИС без даты свежести
- GIVEN 2ГИС 4.9 и 80 отзывов, даты последнего отзыва нет
- WHEN считают индекс
- THEN репутация +2, не +3
- THEN причина не «не ясно какой свежее»

#### Scenario: Одна карта с высоким рейтингом
- GIVEN только 2ГИС 4.6 и отзывы, дат свежести нет
- WHEN считают индекс
- THEN репутация +2, не +3
- THEN вклад 40% от максимума блока с этими баллами попадает в итог

#### Scenario: Высокий рейтинг и отзывы за 90 дней
- GIVEN 2ГИС 4.8, 80 отзывов, последний 01.08.2026, дата расчёта 02.09.2026
- WHEN считают индекс
- THEN репутация +3

#### Scenario: ЕГРЮЛ есть, реестры пустые
- GIVEN дата регистрации 2014 и Федресурс и КАД «не найдено»
- WHEN считают индекс
- THEN устойчивость не считается
- THEN нет текста «долгов нет»

#### Scenario: Реестры открылись
- GIVEN Федресурс и КАД с полкой found, оба значения «не обнаружено», дата регистрации 01.04.2014, дата расчёта 02.09.2026
- WHEN считают индекс
- THEN возраст >5 лет (+3) и бонус «нет судов» (+1)

#### Scenario: Нет ни одного блока
- GIVEN все сравниваемые поля пустые
- WHEN считают индекс
- THEN итог не число 0
- THEN пометка что индекс не найден
