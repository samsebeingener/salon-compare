# Proposal: fix-empty-site-html

## Why

Живой прогон 2 сентября 2026, 19:14: у Pink Lemon «сайт о нас» и ЕГРЮЛ пустые. Зацепка `https://pinklemon-nails.ru/baumanskaya` отдаёт 404 (`empty`), живая страница — `baumanskaya.html` (meta description есть). Официальный ЕГРЮЛ — `blocked`. РБК по ОГРН работает, но только если ОГРН уже известен. У карточки 2ГИС `org.ogrn` / `itin` / `contact_groups` пустые (ключ без этих полей или каталог их не отдаёт). Поиск РБК по вывеске «Pink Lemon» / «Вишня» даёт десятки чужих юрлиц — первую карточку брать нельзя. Третья зацепка ОГРН `1147746349552` в том же прогоне ЕГРЮЛ заполнила (слабо, РБК).

## What Changes

- Если GET сайта `empty` (404) и в пути нет расширения — один повтор на `{url}.html`. 403/капча — не ретраим как «другой файл».
- Если в HTML сайта есть явный маркер `ОГРН` + 13/15 цифр, а на карте ОГРН нет — юрблок идёт по этому номеру (дальше как сейчас: ЕГРЮЛ → РБК → rusprofile). Голые 13-значные id в скриптах MUST NOT считать ОГРН.
- README: вечерний прогон. 2ГИС на этих карточках ОГРН не отдаёт. Без ОГРН юрполя честно пустые. Поиск РБК по названию салона не делаем.
