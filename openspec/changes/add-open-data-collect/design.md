# Design: add-open-data-collect

## Context

Intake уже отдаёт три `VenueCandidate`. Сбор не должен ходить в сеть из pytest. HTML разбирается в Pydantic-схему; в тестах парсер и API подставляются.

## Goals / Non-Goals

**Goals:** каскад поля, независимость тройки, соседи 500 м, один GET сайта, таблица в UI.

**Non-Goals:** ЕГРЮЛ, формула баллов, SQLite, живые вызовы в CI.

## Decisions

- Порты: `MapApi` (карточка + соседи), `HtmlFetcher` (один GET → ok / blocked / empty), `HtmlParser` (dict → `HtmlExtract` через Pydantic).
- Каскад в `collect.py`: API значение не `None` → берём; иначе один HTML; иначе `trust=missing`, `value=None`.
- Ноль отзывов из API — валидное значение; отсутствие ключа в JSON — `None`.
- `httpx` с `trust_env=True` только в адаптерах; тесты адаптеры не вызывают.
- Без ключей карт приложение не падает: API возвращает пустые карточки, поля «не найдено».
- Зависимости: `pydantic`, `httpx` — нужны для схемы HTML и GET; пользователь продолжил пайплайн после явного указания этих пакетов.

## Risks / Trade-offs

- Живой HTML карт часто закрыт — тогда честно «не найдено».
- Разбор HTML моделью в проде потребует `LLM_*`; без ключа парсер возвращает пустую схему, каскад всё равно соблюдён.
