## Purpose

Каркас репозитория salon-compare: одна команда качества, Docker Compose, секреты в образце окружения, hello Streamlit без сбора салонов.

## Requirements

### Requirement: Одна команда качества ruff, mypy и pytest
Система SHALL предоставлять одну локальную команду, которая последовательно запускает ruff, mypy и pytest. GitHub Actions MUST вызывать ту же команду, без отдельного набора проверок.

#### Scenario: Локальный прогон качества
- GIVEN зависимости проекта установлены
- WHEN запускают единственную команду качества
- THEN выполняются ruff, mypy и pytest
- THEN при успешных проверках команда завершается с кодом 0

#### Scenario: CI совпадает с локальной командой
- GIVEN открыт pull request или push в ветку с workflow
- WHEN GitHub Actions выполняет job качества
- THEN вызывается та же команда качества, что и локально
- THEN тесты в этом прогоне не обращаются к сети

### Requirement: Docker Compose поднимает приложение без ключа модели
Система SHALL поднимать hello-приложение через Docker Compose, даже если переменные `LLM_*` отсутствуют или пустые. Отсутствие ключа модели MUST NOT блокировать старт каркаса.

#### Scenario: Старт без ключа модели
- GIVEN в окружении нет заполненных переменных `LLM_*`
- WHEN выполняют `docker compose up`
- THEN контейнер приложения стартует
- THEN процесс не падает из-за отсутствия ключа модели

### Requirement: Секреты не в git, образец окружения есть
Система MUST не включать `.env` в git. Репозиторий SHALL содержать отслеживаемый `.env.example` с плейсхолдером `TWOGIS_API_KEY`, переменными `LLM_*`, `HTTP_PROXY` и `HTTPS_PROXY`. Система MUST NOT требовать ключ Яндекс Карт. Docker Compose SHALL передавать в контейнер `TWOGIS_API_KEY` и переменные `LLM_*` из окружения или файла `.env`.

#### Scenario: .env не коммитится
- GIVEN в рабочей копии есть файл `.env` с любыми значениями
- WHEN проверяют индекс git и правила игнорирования
- THEN `.env` не предназначен для коммита

#### Scenario: .env.example содержит ключи каркаса
- GIVEN клонированный репозиторий без локального `.env`
- WHEN открывают `.env.example`
- THEN файл есть в git
- THEN в нём есть `TWOGIS_API_KEY`, переменные с префиксом `LLM_`, `HTTP_PROXY` и `HTTPS_PROXY`
- THEN в нём нет ключа Яндекс Карт

#### Scenario: Compose прокидывает ключ карт
- GIVEN заполненный `.env` с ключом 2ГИС
- WHEN поднимают приложение через Docker Compose
- THEN контейнер получает `TWOGIS_API_KEY`
- THEN ключа Яндекс Карт в compose нет

### Requirement: Прокси для LLM из РФ
Система SHALL читать `HTTP_PROXY` и `HTTPS_PROXY` из окружения. Клиент к модели MUST передавать `trust_env=True`, чтобы при недоступности LLM из РФ работал прокси. Пустые значения MUST означать работу без прокси. README SHALL описывать эти переменные.

#### Scenario: Образец и клиент уважают прокси
- GIVEN в `.env.example` есть `HTTP_PROXY` и `HTTPS_PROXY`
- WHEN собирают HTTP-клиент для модели
- THEN клиент доверяет переменным окружения (`trust_env`)
- THEN в README указано, зачем прокси нужен из РФ

### Requirement: Streamlit отвечает по HTTP после Compose
После успешного `docker compose up` система SHALL принимать HTTP-запрос к опубликованному порту Streamlit и отвечать без ошибки соединения.

#### Scenario: HTTP после compose
- GIVEN `docker compose up` завершил старт приложения
- WHEN клиент делает HTTP-запрос к опубликованному порту Streamlit
- THEN соединение устанавливается
- THEN ответ не является ошибкой недоступности сервиса

### Requirement: Каркас — hello, без сбора салонов
Интерфейс SHALL принимать три зацепки и MAY показать таблицу собранных полей со ссылкой или «не найдено». Система MUST NOT строить индекс привлекательности и MUST NOT выдавать вывод модели как инвестиционный совет.

#### Scenario: Нет сбора салонов
- GIVEN запущенное приложение
- WHEN пользователь открывает интерфейс и успешно разбирает три разные зацепки
- THEN видны поля для трёх зацепок
- THEN видна таблица полей или пометки «не найдено»
- THEN нет индекса привлекательности и нет совета «покупай»

### Requirement: Файл SQLite не коммитится
Система SHALL хранить будущую SQLite-базу одним файлом рядом с проектом. Git MUST игнорировать файлы `*.db`, `*.sqlite` и `*.sqlite3`.

#### Scenario: Файл базы вне git
- GIVEN рядом с проектом появился файл `*.sqlite` или `*.db`
- WHEN проверяют git status и `.gitignore`
- THEN файл базы не попадает в коммит

### Requirement: Тесты без сети
Тесты MUST выполняться без исходящих сетевых запросов. Ответы внешних систем SHALL подменяться фикстурами.

#### Scenario: Pytest без интернета
- GIVEN тестовый набор каркаса
- WHEN запускают pytest
- THEN прогон не ходит в интернет
- THEN внешние ответы, если фигурируют, берутся из фикстур
